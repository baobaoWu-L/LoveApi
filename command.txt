========================================================================
 Love Api 平台 —— 本地编译 / 启动 / 账号 / 数据库架构 命令速查
========================================================================
（所有命令默认在仓库根目录 D:\LoveApiPlatform 下执行）
项目使用 docker compose -f docker-compose.mysql.yml 管理后端 + 前端 + Redis + MySQL。
前端由独立的 nginx 容器（love-api-frontend）承载，/api 与 /v1 反代到后端。

------------------------------------------------------------------------
一、Go 后端编译
------------------------------------------------------------------------
cd D:\LoveApiPlatform
go build ./...                         # 编译校验后端所有包
go vet ./...                           # 静态检查（可选）

# 重新构建后端镜像（改动 Go 代码或内嵌前端 dist 时）
docker build -f Dockerfile -t love-api:latest .

# 仅编译可执行文件，不打包 Docker（可选）
go build -o love-api ./main.go

------------------------------------------------------------------------
二、前端容器构建 / 启动
------------------------------------------------------------------------
# 构建前端镜像（npm 包原名 loveapi-web，容器内用 bun install + rsbuild build）
docker build -f Dockerfile.frontend -t love-api-frontend .

# 一键启动/更新所有服务（backend + frontend + redis + mysql）
docker compose -f docker-compose.mysql.yml up -d

# 仅重建前端容器 / 重启指定服务
docker compose -f docker-compose.mysql.yml up -d frontend
docker compose -f docker-compose.mysql.yml restart backend

# 查看日志
docker compose -f docker-compose.mysql.yml logs -f backend
docker compose -f docker-compose.mysql.yml logs -f frontend

# 停止全部
docker compose -f docker-compose.mysql.yml down

六、核心表（GORM 自动迁移，位于 love_api 库）
------------------------------------------------------------------------
users             用户表（username/role/status/quota/password）
channels          API 渠道表
models           模型与额度映射表（model_name/model/supported/ratio）
abilities        渠道模型能力
options          系统配置键值表（HeaderNavModules、RegisterEnabled 等）
logs             请求日志
redemptions      兑换码
token            令牌（API Key）

七、本地前端开发（可选，不用 Docker）
------------------------------------------------------------------------
cd web\classic
bun install
bun run dev        # 开发服务器（默认代理 /api、/v1 到 http://localhost:3000）
bun run build      # 生产构建，输出到 web/classic/dist
bun run typecheck  # tsc 类型检查
bun run i18n:sync  # 同步 i18n 文案
